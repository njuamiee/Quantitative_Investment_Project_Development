# 自动因子反馈实验（两轮、外测前冻结）

本实验在已研究过的北交所历史上开发，不能把2026年包装为研究者从未查看的全新样本。程序仍严格隔离筛选与后段评价。

训练：2023-01-01至2025-06-30；验证：2025-07-01至2025-12-31；后段评价：2026-01-01至2026-09-30。各段仅使用在下段开始前已经结束的五日收益答案。

最多两轮：第一轮6个公式；读取训练/验证的通过和失败理由后，再提出最多6个公式。反馈阶段通过Parquet日期过滤不读取2026年记录，不计算后段IC。候选合计最多12个，不根据后段成绩追加第三轮。

固定筛选：训练有效覆盖≥70%，训练至少15日且每日≥10股，|平均RankIC|≥0.02，验证按训练方向使用后的平均RankIC≥0.01，和任何父输入的相关系数绝对值<0.995。最多保留3个，按验证IC降序、ID升序；候选间训练相关系数绝对值≥0.92时只留前一个。负相关方向乘-1使用，不能看到后段结果再翻转。

增量实验：从原始x列剔除旧x_llm列，按旧训练筛选函数选100列，建立基准LightGBM；增强模型只在这100列后增加通过的最多3列。二者使用相同叶子数、学习率、训练行、样本权重和基准验证选出的树轮数；重训只用2026年之前成熟答案。100列清单和新增列冻结后再评分2026年。

账户比较固定四条：基准/增强×全仓/上涨广度门，Top20、每5交易日一批、次开盘买第5日收盘卖、每边5bp、100万元。所有结果保留；通过IC不等于新增收益。没有通过则明确记录“无新增因子”，不强塞公式。

提案来自本对话的Codex，程序负责校验、反馈、训练和评价；没有谎称安装了本地大模型、调用了RD-Agent或全自动无人干预平台。训练/验证摘要反馈给Codex，不发送逐只股票行情到外部模型接口。
