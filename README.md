# 北交所量化选股与消息驱动模拟项目

更新：2026-10-29 · 当前工作分支：`codex/vnpy-message-driven`。

这个项目利用历史数据给股票排序，研究仓位和风险规则，再用消息驱动系统模拟委托、成交与记账。大规模研究和服务器历史回放已完成；逐月选择系统尚未同时达到收益风险目标，今天的实时行情尚未接通。

## 当前结论

- **研究层**：8,640个模型配置、967,680次滚动拟合、27,993,600个账户参数配置全部完成，另有1,152组分钟实验。配置共享预测，不能当作独立统计证据。逐月系统在2025-07-02至2026-10-19收益−6.46%、最大回撤19.66%、夏普−0.46、卡玛−0.26，未同时达到目标。事后最佳固定组合不等于当时能选中它。
- **执行层**：历史Tick已从专属ClickHouse数据库经vn.py原生加载器推给策略。14组实验完成，两版策略的数据库迁移对账通过，8组截断/未来扰动检查通过。原生与自建撮合都在同一服务器对照，成交与收益并不相同；详见报告中的流动性差异证据。
- **代码位置**：本地保存完整研究工程，服务器部署执行发布包。重新核对的17个`quant_message` Python模块完全一致，两个环境与整个文件夹并非完全相同。Git推送不会自动部署。
- **尚未证明**：原始因子发布时间完全可靠、旧优化策略完整等价复现、未来稳定盈利、实时纸面模拟与一键真实交易。当前检查不能代替这些验收。
