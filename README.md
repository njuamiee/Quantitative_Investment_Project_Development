当前事实：本轮每日股票池最多 100 只，已完成季度滚动与训练内去重。北交所主模型价格研究账户累计 +64.47%、最大回撤 -45.33%，2026 年截至 9 月 29 日亏损 -26.60%；沪深样本筛选模型为 -40.35%。HMM 未优于固定减仓对照。真实分红送转、历史资格和商业平台仍未验收；因子可用时间暂按文件日收盘后处理，不代表已证明历史发布时点。

最新版里的 `factors/` 和 `backtest/` 仍包含可复用的旧因子评价、滚动规则、绘图及测试。它们不是 LightGBM 滚动训练的替代品；其中默认相对数据路径和静态 Top100 名单不能直接代表本机正式数据配置。使用时显式指定实际因子与行情路径。旧源代码快照中的 AGENTS/README 保留了原作者环境描述，本机使用上述虚拟环境。
