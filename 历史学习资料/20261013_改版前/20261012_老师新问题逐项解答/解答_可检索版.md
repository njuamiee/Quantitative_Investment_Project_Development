## 04  LightGBM参数怎么确定


原40因子曲线对应LightGBM回归模型，学习的是每日股票未来收益的横截面排名，目标target=收益百分位排名−0.5。模型输出用于选股排序，不是直接预测收益百分数。[O1]

| 参数 | 原图设置 | 实际作用与选择方式 |
| --- | --- | --- |
| num_leaves / max_depth | 15 / 5 | 事先设定树复杂度；并未从完整网格寻优。 |
| learning_rate | 0.03 | 固定每轮更新步长；没有做学习率搜索。 |
| n_estimators | 上限400 | 验证期连续35轮无改善就早停，保存最佳轮数，再重拟合。 |
| min_child_samples | 200 | 限制叶节点样本数。 |
| reg_lambda / reg_alpha | 5 / 0.1 | 树叶权重的L2/L1正则固定设置，与Ridge alpha=10不是同一参数。 |
| 目标 / 验证指标 | 平方误差 / l2 | 未另指定eval_metric，使用该回归目标的默认l2；早停没有直接优化净值或回撤。 |
| 随机性 / 并行 | seed=20260930；4线程 | deterministic=True，force_col_wise=True；原主配置没有启用80%行列抽样。 |

后续10月8日扩展比较了20/40/60/80/100个因子、叶子数7/15/31，以及80%行列抽样的种子17/29。每季度按此前验证期平均每日Rank IC选择数量或叶子设置，数量相同时采用确定性规则；测试期最高收益方案只作为事后对照。[O4]

早停的验证l2与选择因子数量的验证Rank IC不是同一个指标。若要让选择标准完全一致，下一轮应预先声明验证主指标，并将早停监控和候选比较如何配合写入协议。不能说此前所有参数都已经由统一目标调到最优。

最新版主LightGBM另设180轮、学习率0.035、叶子15、深度5、最小叶样本160、L2=12、列抽样0.8；没有沿用旧版400轮+35轮早停。模型文件和图表应注明版本，不能混用参数解释。[N1；S2—S3]


## 05  Ridge的实现、正则和共线性



### 实际拟合目标


对当轮选出的相同40个输入，旧版拟合带截距的线性模型：预测分数=b+Σβj·xj。优化目标为Σ(y−b−Xβ)²+10Σβj²，截距不受此项惩罚。alpha=10为固定研究基线，未通过RidgeCV或验证网格证明最优。[O1；S1]

输入在每个交易日股票池内先转成百分位排名−0.5；Ridge将缺值填0作为中性近似，LightGBM原版保留缺失值。这里没有另外拟合StandardScaler；代码导入的StandardScaler用于HMM。0也不是每一天、每一列严格精确的样本均值。


### 为什么要正则，以及它没有解决什么


对中心化后的矩阵，β=(XᵀX+αI)⁻¹Xᵀy。给对角线加α可以缓解相关输入导致的系数不稳定；Ridge通常不会把全部冗余因子系数直接变为0。先做相关性去重，再做L2收缩，仍不等于消除了所有共线性、行业暴露或市场风险。

| 2026Q3实际核对 | 数值与解释 |
| --- | --- |
| 最终重拟合样本 | 62,466条；40维输入；缺失比例1.75%。 |
| Gram矩阵条件数 | 未加正则398.45；加10I后381.47。本轮改善有限，不能夸大正则效果。 |
| 截距 | 0.00483320 |
| 两个系数例子 | GT046：0.024445；GT067：-0.049084。系数由联合拟合决定，不等于单因子IC。 |

这里的条件数为中心化、缺值填0后的XᵀX最大与最小特征值之比，是本次对已存数据的描述性诊断。下一轮可在每个训练/验证窗口内比较alpha候选，并冻结选择；不能在最终测试回撤变大后反复调整alpha再重报同一测试。

最新版主Ridge使用最多60因子、alpha=180；月度短窗扩展比较alpha=20/180。这些配置均不能替代对原图alpha=10的解释。[N1—N2]


## 06  40因子筛选：输入与每日评分



### 候选库究竟有多少


原北交所模型候选共304项：供应商Alpha101的101项（c01）+Alpha191的191项（c02）+本地12项价格/流动性特征。没有把因子字典里的2,447个数值字段全部放入这次模型。字典可识别字段与已具备可用历史面板的训练字段不是同一集合。[O1—O2]

12项本地特征为mom5、mom10、mom20、mom60、vol10、vol20、vol60、adv20、amount_ratio、range20、log_illiq、observed_days。x_前缀表示该特征经过当日横截面排名变换。


### 先决定在哪些股票上评价


每天用过去20日平均成交额选择最多100只；要求至少60个有效成交历史日、近20日至少16日有效成交，以及当日有效正价格/成交额/成交量。这是每日动态股票池。现有文件能覆盖的证券范围仍存在历史退市与证券主表不完整的限制。


### 每个因子的每日Rank IC


在该日股票池中，对每个因子和未来收益使用共同有效的股票样本重新排名，再算排名之间的Pearson相关，即Spearman Rank IC。共同样本少于30只时当天记缺失。旧标签为r(t)=原始收盘价(t+5)/原始开盘价(t+1)−1。

例如IC=−0.13表示因子值较高的股票往往对应较低的未来收益排名，是可反向使用的信号；它不表示亏损13%、胜率13%，也不能单独决定组合收益。


### 只汇总当前训练窗口


对当前训练期每天的IC等权平均，得到mean_ic；计算IC标准差、ICIR=mean_ic/std(IC)、正IC天数比例、有效IC天数。覆盖率按训练股票日行计算：非缺失行数/全部训练行数。先计算全历史IC文件仅为缓存，筛选时只截取本轮训练日期。

因子排序既不用当前季度测试收益，也不用最终全样本特征重要性。LightGBM重要性是在筛选和拟合之后保存的解释产物，不是选出这40项的入口。


## 07  40因子筛选：门槛、去重与统计


| 顺序 | 实际代码规则 |
| --- | --- |
| 质量过滤 | 覆盖率≥70%；有效IC天数≥100；平均IC非空。缺失或常数导致无有效IC的特征不能入选。 |
| 排序与候选预算 | 按\|mean_ic\|降序，再按覆盖率降序；截取前100项。强负IC也会靠前。 |
| 估计相关性 | 每个训练日，对候选因子两两共同有效股票计算Spearman相关；至少30对；再对每日有符号相关取平均。 |
| 贪心去重 | 按候选排序扫描。若与任一已选因子满足\|平均相关\|≥0.85，则删除当前因子，记录最先阻挡它的因子。 |
| 数量上限 | 未被相关性阻挡且当前不足40项时入选；满40后的非冗余项标为预算排除。可能少于40，本次8轮均足额。 |
| 模型拟合 | 因子身份在训练窗内确定；验证用于早停/后续数量选择；测试前按已冻结配置重拟合。 |


### 统计指标算了，但哪些真正参与筛选


旧代码对IC序列使用5阶Bartlett权重的HAC标准误，并计算双侧正态近似p值；再按304项做Benjamini–Yekutieli型FDR修正。q值、ICIR和正IC天数比例均保存，但没有进入入选判断。真正的排序指标是平均IC的绝对值。

复核发现：2024Q4选中40项中，只有30项的q<0.05；2025Q1为39项，此后6轮为40项。所以“每轮40项都通过显著性门槛”不成立。即使某轮全过，也不是因为代码把q<0.05设为门槛，更不能说明多轮策略搜索已经完成全族校正。

去重用的是|每日相关的平均值|，不是每日绝对相关的平均值；正负相关随阶段切换时可能互相抵消。它也只排除成对高相关，不能排除多个因子的线性组合共线性。这是下一轮需要评估的具体局限。

### 可以合理解释的机制，但尚未完成因果归因


新增因子会改变两类模型的使用方式：树模型可在不同分支选择不同变量及阈值；Ridge把所有变量线性相加，更多弱信号或同类暴露会改变联合系数。固定alpha并不会自动为每个因子数量匹配相同的有效复杂度。这些都是待检验机制，不能直接断言图形已经证明它们。

回撤又取决于持仓、市场方向、流动性约束和历史净值峰值；它不是IC的单调函数。Ridge100全期累计收益113.79%，高于Ridge40的88.24%，但最大回撤47.80%也更大；收益更高不代表风险更小。

最具体的证据是两个最大回撤的起点不同：LGB100从2026-03-03峰值跌到7月24日；Ridge100从2025-08-25峰值跌到2026-07-20。不能把这两条曲线当成同一时间区间下的受控因果比较。

下一轮用相同日期、相同持仓约束做比较，再检查新增因子的组别、样本外增量IC、系数/重要性漂移、行业与风格暴露，并在验证窗内选择正则。不能仅因100项在本段更好就宣布它是通用最优数量。

## 12  调仓、持有、标签与本次成本口径



### 旧版实际是每日开新批次


原账户每天收盘评分，下一交易日开盘买入Top5；每天新批次预算不超过净值20%，单股总上限10%，买入受过去20日成交额1%约束。该批次计划在信号日t+5收盘卖出，受T+1和不可成交条件影响时延期。季度重训、每日评分、每日开批次与5日标签是不同频率。


### 老师写的IC(5)与旧代码差一个交易日


| 口径 | 预测/评价收益 |
| --- | --- |
| 旧版及新版h=5 | close(t+5) / open(t+1) − 1；新版使用后复权价格形成标签。 |
| 老师PDF字面公式 | close(t+5+1) / open(t+1)，即close(t+6) / open(t+1)；写成收益再减1。 |
| IC定义 | 每个信号日按股票截面算Spearman(s(t), r(t))；减不减常数1不改变Rank IC。 |

t按市场交易日序号计算，不是自然日。本次后续协议按老师明确给出的t+6标签登记，不能把现有t+5结果当作已满足。同样叫“5日”，起算方式必须在字段里写出。

还要说明一个执行边界：若严格每隔5个交易日发一次信号，新批次会在t+6开盘进入，而上一批在t+6收盘退出，存在同日重叠。若全仓且不融资，不能假定早盘已有晚间卖出现金。后续账户须预留现金/分批；如另做不重叠开盘换仓，标签也须改为相同开盘端点，作为单独预登记对照。


### 按最新要求统一研究成本与研究范围


老师明确“万分之一、双边收取”：买入与卖出各0.0001，即每边1bp；10万元买入收10元、同额卖出再收10元。后续基准不另加滑点。这与旧图15bp、新版5bp均不同；1bp情景曾有局部测试，也不能代替按新标签、新持有制度重新训练和回测。

先报告因子IC、分层收益和简单选股账户；HMM、分钟执行、单独分红到账模块暂缓。已有相关研究作为背景归档，不混入本次选股模型验收。

### 本次简化研究如何避免重复计算分红


因子检验和收益分层统一使用后复权开/收盘之比；若在简化研究账户里也直接使用这个连续收益口径，就不再额外把同一次分红现金加回。实际现金/股数账户只能用真实成交价格，后续若恢复该模块，再单独还原到账日、送转可卖日和税费。

后复权价格代表连续研究价格，不是当日券商成交报价；也不能仅凭它就认定所有历史资料具有point-in-time属性。当前供应商快照、证券退市范围、因子计算版本和行情修订都需要单列。


### 回撤归因的执行顺序


先冻结数据和日历，列异常清单；再定位回撤峰谷与最差日，按股票核验收益贡献；最后比较相同价格口径下的股票池、行业/风格对照。未定位原始原因前，不靠删掉亏损日期或反复调参让曲线变好。核验后若确属错误，应修正输入、记录原因并重跑全部受影响方案。


## 14  市场、行业和风格中性化方案



### 当前状态：尚未完成老师要求的完整中性化


原40因子筛选进行了相关性去重；这与行业中性、市值中性和市场beta控制不同。最新版的HMM和低仓位也不能替代中性化。当前没有已核验的完整历史申万行业生效区间，不能把今天的行业标签直接填回过去。


### 先对因子去掉可观测暴露


每个交易日、每个候选因子，在当时可得股票池上做截面回归：factor = 截距 + 行业哑变量 + log(流通市值) + 过去窗口beta + 波动/动量风格 + 残差。用残差重新排名，再在训练窗内计算IC和筛选。行业截距编码需避免虚拟变量陷阱，小样本行业要预先定合并规则。

市值和股本应使用公布/可得日；beta只用过去收益，例如过去252日且有效日不少于126日。风格集合与处理顺序预先固定，不依据当季测试好坏增删。若可得时点缺失，应明确标为探索性近似，不能宣称PIT中性化已完成。


### 再约束实际持仓


因子残差中性不保证TopN持仓中性。组合需要独立约束单股、行业与风格偏离，约束参照可采用当日可得股票池权重，并单独与北证50行业结构比较。候选约束应在训练/验证阶段设定或选择；不把某组尚未验证的行业上限直接称作最优方案。

纯多头且不做股指/其他对冲时，通常只能控制市场暴露，无法承诺严格的零市场beta；若做残差收益目标或行业相对排名，也不等于实际账户完全市场中性。该约束必须与可交易工具和仓位条件一致。


### 需要补齐哪些字段，如何验收


至少需要stock_id、industry_code、industry_level、effective_from/to、published_at、available_at、数据版本；以及历史流通股本、市值、证券状态和代码沿革。用当时可得记录做as-of关联。对照原始因子、行业残差、行业+风格残差、组合约束四组，统一标签、费率、数据和测试窗口；同时报告IC、净收益、回撤、换手与暴露偏离。


## 15  下一轮嵌套滚动实验的严格协议


以下是按老师新要求拟定的实现协议，尚未执行成一组新的验收结果。采用固定长度滚动窗：名义训练504日、验证126日、测试为随后一个自然月内的交易日；锚点每月前移，拼接互不重叠的测试预测。扩展窗作为另一个预先声明的对照。

| 环节 | 必须落实的边界 |
| --- | --- |
| 固定定义 | 冻结股票池、复权版本、标签端点、信号间隔、手续费1bp/边、比较模型与选择指标。 |
| 训练窗 | 所有清洗参数、候选因子筛选、IC方向和中性化训练相关统计只用该训练窗；不得全样本先筛。 |
| 隔离/标签剔除 | 同时检查train→val和val→test：样本的label_exit必须严格早于下一段开始。若标签为t+6，末端需按6日偏移处理，不能机械沿用5日。 |
| 验证窗 | 只用于早停、因子数与正则/树复杂度的预登记选择。选择指标和同分规则固定，保存全部候选。 |
| 最终拟合 | 固定已选择的因子身份和参数，用测试起点前已成熟的历史重拟合；不拿测试损失做早停。 |
| 测试月 | 保存一次不可变预测及输入哈希；评估后不回头重选这段的配置。其已成熟数据将来可自然进入后续训练窗。 |

代码现状是按标签实际结束日剔除跨界样本，没有一个对所有实验统一硬编码的“20日隔离”参数。若某方案预测t+20，边界按20日；若统一采用老师t+h+1规则，h=20的标签最晚在t+21，检查也要随之变化。

“每窗只评一次”意味着不利用其结果回头改本窗，并不禁止该月过去之后作为后续模型的历史训练数据。为防止研究者反复试同一历史，应保留当前数据之前的探索标记，并从方案冻结后积累真正新增、未看的数据作为后续检验。


## 16  重训频率、超参数锁定与40是否最优



### 为什么建议月度，而不直接改成每日重训


重训可适应市场变化，也会增加估计噪声和计算成本。原图是季度重训，最新主模型同样按季度；另有1/5/20日预测、63/126/252日训练窗、月度更新的短窗研究，使用Ridge、浅树和IC加权。这组不能直接称作老师新协议结果，因为成本、标签与验证结构并不完全相同。[N2]

该480组短窗组合的完整历史有41组达到此前指标，但近一年达标0组、近半年0组、三个区间同时达标0组。月度更新已经尝试过，也没有证据支持“只要更频繁重训就能解决近期退化”。


### 下一轮的可复核选择规则


固定每月一次作为基线，参数仅在当轮验证集内选择，或在首轮内层搜索后冻结。每日只更新特征和评分，不把当天回测不佳当作任意换模型的理由。若另做触发式重训，应预先定义监测窗口、阈值、冷却期和可得标签，保存触发日志。

因子数候选可沿用20/40/60/80/100；Ridge正则候选与树复杂度采用有限、预先登记的集合。先按验证Rank IC和稳定性筛选，再按预登记的净收益/回撤约束决定可用组合。具体优先级和同分规则必须在测试前确定。


### 40的定位应怎样向老师表述


40是旧基线的维度预算，便于控制复杂度和解释；当前没有理论证明或独立新测试证明它最优。20到40收益提高，40到60又变差，因子数与效果并非单调关系。10月8日的验证选数量方案可以作为方法演示，但其测试历史已被查看，不应拿同一段历史反复寻找“最佳40”。

旧8轮相邻名单的重合数依次为[29, 34, 28, 36, 34, 35, 37]，每轮分母40；累计77项，始终入选14项。这种名单变化说明筛选随训练窗更新，也提示需要报告因子选择稳定性和换手影响。
