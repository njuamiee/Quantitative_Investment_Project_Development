# 新一轮组合研究协议（2026-10-26）

本文件在这一轮完整队列结束前固定。行情截至2026-10-19，研究者已经看过这段历史；本轮是严格控制程序时间顺序的探索研究，不能重新命名为从未查看过的独立测试。历史未达到目标时，不通过改日期、删失败组合或改变收益口径将其改成达标。

## 1. 要解决的问题

系统不是每天猜一个指数涨跌，而是给当时股票池中的股票排序，并回答：可以买哪些、最多买多少只、每只投多少、总共投入多少、何时卖、卖不出去怎么办。模型给的相对排名不等于绝对上涨概率。

在每个月的第一个信号日，系统查看此前候选账户的真实模拟记录，选定本月使用的模型配置和交易规则；本月结束后再向前推进。选型只使用此前已发生的收益，下一月不能看到自己的答案。选型频率（月度）、模型参数重训频率（日/月/季）、因子清单更新频率（季度）和交易换仓频率（每日/预测期限）是不同的事情。

验收目标：夏普（年无风险利率1.5%）>1、卡玛（几何年化收益/最大回撤）>2、最大回撤<30%。还必须看净收益、成本敏感性、仓位、成交限制及相对简单基准的改善。目标是研究门槛，不是预先承诺的结果。

## 2. 固定的模型空间

| 维度 | 本轮取值 |
|---|---|
| 预测期限 | 1、2、3、4、5、10、15、20个交易日；按用户后续指示缩减 |
| 候选因子上限 | 20、40、60、80、100；实际通过筛选不足时如实记录 |
| 模型家族 | Ridge、IC、HMM条件IC、LightGBM回归、LightGBM Ranker、XGBoost、ExtraTrees回归排名、CatBoost |
| 模型重训 | 每交易日、每自然月、每自然季度 |
| 训练窗口 | 126、252、504个已经成熟答案的信号日 |
| 因子库 | 日频311列；日频加54个AI公式假说；前两者加1601个保守供应商候选字段 |

共8×5×8×3×3×3=8,640个模型配置。每个配置有多次真实滚动拟合，拟合次数单独统计。ExtraTrees采用回归分数排序，不虚构一个库里不存在的“ExtraTreesRanker”。按用户明确回复，本轮忽略“XJ/Jev”模型。

这里的拟合次数指已经完成并留存的主网格滚动拟合；不包含HMM预处理、分钟附加模型、跨平台核验及中断重试。完整主网格预计留存967,680次滚动拟合。计算按960个核心配置、960个额外XGBoost配置、6720个其他扩展配置分片；前两片在本机，最后一片在原数据服务器的独立临时目录。八类模型的同配置跨平台核验中，七类排序一致，XGBoost出现明显差异，因此其所有正式组合都固定在同一Windows环境，避免混入平台差异。

树的复杂度是预先固定的：LightGBM/Ranker/XGBoost/CatBoost为64轮；ExtraTrees为48棵树；各模型使用固定正则化和随机种子。树轮数不是通过后段表现调出来的。这个注册空间覆盖所列类别，并不代表穷举所有连续参数或世上所有模型。

## 3. 固定的交易规则空间

| 维度 | 取值 |
|---|---|
| 最多持股数 | 5、20、40 |
| 权重 | 等权、逆历史波动 |
| 基础目标仓位 | 100%、50%、按股票池历史波动率向15%缩放且不加杠杆 |
| 市场状态约束 | 无、两状态HMM、三状态HMM |
| 退出与回撤 | 常规换仓、成本价下跌8%止损、最高收盘价回撤10%追踪止损、账户回撤分级降仓 |
| 集中度 | 无额外分组约束、行业30%且市值组50%约束 |
| 新增买入条件 | 按排名、反弹确认 |
| 股票池规模 | 动态成交额前50、前100；均在原合格池内限制 |
| 换仓间隔 | 每日、与预测期限相同 |

常规期限每个模型配置有3,456个规则组合；1日期限下两种换仓间隔完全相同，去重后1,728个。因此完整登记**27,993,600个模型×规则配置**。重复经济路径仍可能出现在不同规则之间，不把这些配置称为独立统计样本。每个配置都保留亏损、零交易、低仓位和失败原因。

所有组合共用单股不超过账户10%的下单上限；因此Top5满配也只有最多50%股票仓位。HMM防守状态下额外将最多买入数压至1，同时将目标总仓位压至5%，不会把全账户集中到一只股票。“全仓”在注册表中表示基础仓位上限，不表示忽略其他约束后的实际仓位一定100%。

因子库和模型维度相同的配置可以复用同一份预测，改变风控后必须运行独立账户。复用数据/预测不冒充重新训练模型。

训练池仍是原动态Top100；Top50是成交候选子池约束，并未另外在Top50内重算全部因子或重训一套模型。15%波动档使用股票池历史波动作为市场风险代理，不声称精确预测所选组合的协方差或保证实现波动恰好15%。

## 4. 收益标签和交易时钟

信号在t日收盘后可用。所有期限统一定义为：t+1开盘买入，t+h+1开盘卖出的调整后价格收益。h=1也跨过一个完整隔夜交易日，符合买入当日不能卖出的约束。

模型训练时，标签退出日必须严格早于拟合日。20日预测不能把最近20日尚未结束的收益当作答案。标签在完整市场交易日历上计算，不在“这只股票进入股票池的记录行”上移动20行。

交易账户采用原始价格和单独的分红拆股事件。h是预测期限，也是一个可选换仓间隔；不是保证每笔持仓恰好持有h日。选中股票可继续持有，止损可能提前退出，停牌或成交限制可能延后退出。这与旧版固定第5日收盘平仓口径不同，不能把两个版本收益直接归因于模型改进。

## 5. 训练、验证和评价日期

共同预测/账户段：2025-07-02至2026-10-19，314个交易日。最近评价段沿用2026-05-22至2026-10-19，便于查看此前失效时段，但它不是新独立样本。

每次拟合向过去取126/252/504个已成熟信号日；因子清单每季度更新，也只使用当时已经成熟的训练答案。覆盖至少70%；至少40个有效IC日；稳定性评分为|平均IC|/(IC标准差+0.05)，并按可用日数缩减；训练样本内相关系数绝对值≥0.98的候选不重复保留。扩库来源另有限额。相关性检查最多使用训练段的确定性抽样约3000行，不含未来股票日。

“训练占比”在滚动系统里不是把全历史随机分成70/20/10。例如252日训练+126日既往账户验证+约21日下一月，约占63%/32%/5%；126日训练时约46%/46%/8%；504日约77%/19%/3%。此外有h相关的标签成熟等待。它们是相对时间跨度说明，不表示这些区间可以随机打乱，也不表示滚动账户验证时从不使用前一验证段里后来成熟的训练答案。

前63/126日的候选收益均来自当时的向前滚动预测。每月分别计算两段夏普、卡玛、回撤，取min(夏普,卡玛/2)，再取两个窗口较差者。收益非正、回撤≥30%、没有有效风险比率或没有买入的候选不入围。满63日才开始选型；不足126日时第二窗口使用可得历史。新候选只比现任高≤0.10且现任仍合格时，保留现任以降低切换。

先选规则，再运行同一份连续股票/现金账户，保留旧持仓、成本与不能成交的卖单。不能把每个月赢家的独立账户净值直接拼起来。月度选型切换后的第一次信号按新参数重平衡。每月记录完整选择日期、最后验证收盘日、模型配置、规则配置和评分。

无合格候选时同时比较两条预先固定分支：持现金（收益假设0）和动态股票池等权。后者是持有股票，不是“持币”，也不是保证2026Q2/Q3能赚钱的规则。

另增加“季度第一个信号选定股票池、等权买入并在季内持有”的基准，和动态每5日等权换仓分开。该基准使整季持股的收益与风险有明确对照；不通过事后知道哪一季上涨再决定持股。

## 6. 更细的风险设计

HMM每月用此前最多504日数据拟合两/三状态；观测包括市场收益、波动、趋势和上涨广度。状态用训练期市场收益排序；状态概率只向前滤波及一步预测，不做利用未来的平滑。拟合质量不合格时记录回退。状态风险上限和基础仓位上限取较小值。

反弹确认规则：下跌背景下，市场近5日转正、上涨广度>35%、市场距近60日高点回撤超过8%时，最多10%小仓试探；否则可以完全不买。趋势改善但广度仍不足55%时最多50%。候选个股同时要求近2日为正、近5日收益>-2%。这是一项待检验假说，不知道未来最低点，也不保证不会买在下跌中途。

组合回撤降仓：8%以内不额外削减；8%–15%降至基础风险预算一半；超过15%降至十分之一。市场近5日为正且上涨广度>60%时允许恢复到至少一半的风险乘数，避免永远锁在低仓位。仍须通过其他约束。

止损和追踪止损以此前收盘触发，下一开盘尝试执行；停牌、跌停与容量不足时继续待卖。止损后10个交易日禁买。集中度是持仓金额限制，卖不出去的原有持仓也占用额度；它不是严格行业/市值中性。市场价格波动和无法成交可使实际风险短期超限，不能宣称“回撤上限被数学保证”。

常规排名换仓是当次信号的目标仓位订单，未成交部分当次失效，下次换仓重新计算；止损退出一旦触发则持续待卖。这两类订单的有效期不同。真实连续账本保留未卖掉的股份，不会把它们直接变成现金。

## 7. 执行与成本

初始资金100万元，不借钱、不融资、不做空。日线主网格在下一开盘模拟成交；每边5bp合并成本为主情景，逐月系统增加15bp敏感性，保持原选择决定。成本包括佣金/税/滑点的合并近似，不声称逐笔还原真实费率。

最低买入100股，以股为递增单位，不强制100股整数手。正常部分卖出遵守100股最低数量，剩余不足100股只能整体卖出。买卖共享“此前20日均成交额1%”容量。停牌/无有效价格不成交；涨跌停用经分红拆股调整的参考价和约30%阈值近似。真实交易状态、委托队列、价位优先级没有完整历史资料。

分红在除权日即时按税前现金入账、拆股即时调整股份，这是研究情景，真实到账日期与税收不同。无法成交的股票用最后可得价估值；这种估值也可能低估流动性风险。

终审另核对“公司行为发生当天没有开盘/收盘行情”的情况：本批次评价区间内必须为0，否则终审拒绝通过，需要新版本补充停牌期间除权估值处理后重新评价。更早历史确有113个这类事件，不能未经核对把本批次账本扩展到那些日期。

## 8. 扩库、AI候选与分钟实验

完整日频原特征311列；新增54个Codex预先提出的动量风险、反转、恢复、区间位置、成交量条件与加速度假说。部分互为符号或高相关，筛选后会去重，不能把54称为54个独立有效因子。模型代码自动筛选，但没有部署或谎称调用真实外部LLM代理。自动提案接口与历史反馈机制可继续扩展，外部文本模型已按用户要求排除。

此前2445字段供应商库只有154个取样日；1601个保守候选可进入扩库。仅沿用当时已存在的快照，最多4个后续交易日，禁止反向填充。披露/关系历史不可靠的其他字段不进入主验收。供应商文件的历史发布和修订时点仍未独立证明。

分钟数据目前125个交易日，集中在2025Q4和2026Q3。分钟收益因子与分钟成交容量是两种不同用途：前者问“日频排名能否改善”，后者问“计划买入数量能否在窗口内成交”。不能因为缺分钟线就补造成交；分钟配对实验仅用真实覆盖日期，并单独标注评价区间。主网格目前按日线容量执行，分钟研究另行落盘，不将日线近似冒充完整分钟实盘仿真。

## 9. 搜索过多与真实验收

全部亏损与未达标组合都保存。先看逐月选择系统，再看事后赢家。每次报告列出实际拟合数、已完成模型配置数、已完成账户配置数、待运行数、错误数；“注册27,993,600组”绝不表示已经跑完。

给出成本变化、仓位差异、动态等权基准和20日成组的成对重采样。95%区间含0时不能宣布稳定超额。大量试验会产生偶然赢家；普通回测夏普不能直接解释为显著性，最终应结合多重试验校正、未见新数据和模拟实盘观察。当前重采样是对指定逐月系统的描述性不确定性，不是已经完成全部搜索的严格多重比较校正。

2026-10-19之后的数据才可能用于新一期真正向前验证。目前不能生成可靠的11月正式部署包：10月余下数据、全量搜索以及生产环境执行时间均尚未验收。离线历史重训假设在下一信号前完成；需要另测真实服务器截止时间，迟到任务不能倒填上线。

## 11. 中证2000比较的正确解释

1. 在北交所动态池内部，比较选股组合与同池等权，检验北交所的选股增益。
2. 在中证2000当时的真实历史成分股内部，同样比较选股组合与同池等权，检验另一市场的选股增益。
3. 比较这两项增益，研究同一方法能否迁移；不能直接比较绝对收益后宣布算法通用。
4. 官方中证2000指数曲线作为市场参照，其权重、调样和收益时点与研究账户不同，不是严密配对基准。

以前修正实验的历史成分来源仍存在独立核验缺口。该缺口没有因为本轮增加组合而消失；本轮主搜索仍在北交所，不能把登记的北交所模型数量写成中证2000已经重跑的数量。
