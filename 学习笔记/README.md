今晚汇报前建议按这个顺序练习：

1. 讲义第1—8页：讲清“资料→排名→买卖→资金变化”。
2. 第9—17页与第41页：逐条理解老师九项建议及解决边界。
3. 第36—40页：理解本轮新增的数量、参数、分钟和分红实验。
4. 第20—25页：理解SFTP更新和确实需要补齐的资料。
5. 第26—29页：练四分钟讲稿和老师追问，再沿23页PPT完整讲一遍。

第30—34页是术语速查与自测。无需一开始背模型名或公式，先能解释“为什么这么做、数字能证明什么”。100因子历史成绩较好、分钟成交限制使成绩下降、HMM未胜简单对照，都是可以诚实汇报的研究结果。

本轮已经实做五档数量、按过去验证成绩选数量、其他参数与信息时点对照、两段分钟资金账户、沪深Alpha101、分红和后复权实验，并通过59项研究检查。仍缺的核心证据是历史股票资格、真实发布时间与修订记录、分红结算日/新股可卖日/税费，以及指定商业平台验收；讲义没有把这些写成已经完成。
