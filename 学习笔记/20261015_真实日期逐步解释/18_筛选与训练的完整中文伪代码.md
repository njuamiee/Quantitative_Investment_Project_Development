本说明固定讨论2026年4月1日启用的5天LightGBM，避免混用其他季度、期限和旧版本数字。原代码没有改动。这是一份展开计算含义的伪代码，不是直接执行的Python。

数据形状：499个历史输入日期，每日100只股票，原有49,900行。删除19行没有有效答案的记录，剩49,881行。一行代表一只股票在某一天的记录。335列候选经过筛选，最后给LightGBM的输入是49,881行×100列，答案另外保存为49,881个数。日期、股票代码、未来收益均不算进100个输入列。

```text
本次启用日期 = 2026-04-01

选取历史行：
    输入日期在本次允许的历史窗口中
    并且该行答案结束日期 < 本次启用日期
    并且答案有有效数值

本次得到49,881行，输入日期2024-03-01至2026-03-24。
最后一批答案结束于2026-03-31。

对每个日期：
    先按当日历史交易与成交额条件确定股票池。
    对每个候选指标列：
        按当天原值从小到大排名，同值取平均名次。
        指标输入数 = 名次 / 该列有值的股票数量 - 0.5。
        缺值暂时保留为空。
    对当日有未来收益答案的股票：
        答案 = 未来收益从低到高的名次 / 有答案股票数量 - 0.5。

候选名单 = 空
对335个候选列逐一计算：
    有值比例 = 该列在49,881行中有值的行数 / 49,881
    如果有值比例 < 0.70：
        淘汰
    否则：
        对每个历史日期：
            a = 各股票该列输入数 - 当天该列有值输入的平均数
            b = 各股票答案 - 当天答案平均数
            当天IC = 加总(a*b) / 平方根(加总(a*a)*加总(b*b))
            分母为0时，该天IC无有效值，不进入平均。
            求和时跳过对应乘积或平方中的空值。
        平均IC = 有效的每日IC的算术平均
        筛选分数 = 平均IC的绝对值
        加入候选名单

说明：以上保留了现有IC代码的缺失值处理。
它没有在每一列缺值时同步限制答案集合，因此不等同于共同有效股票内重新排名的标准Spearman。

将剩余330列按筛选分数从大到小排序，同分按列名排序。
只在训练记录内，将这些列的空值填成0，计算任意两列的相关系数绝对值。

已选 = 空
按上述顺序逐列处理：
    如果当前列与任意已选列的相关系数绝对值 >= 0.92：
        跳过当前列
    否则：
        加入已选
    如果已选数量 == 100：
        停止筛选

输入表 = 49,881行中已选的100列，空值填0。
答案列 = 与每行对应的答案。
```

100是代码固定的列数预算，180是固定的训练轮次预算，均不是金融定律给出的最优数字。每棵树的列抽样比例是80%，最多15个末端组、最多5层判断，末端组最少约160行。下面按当前无样本权重、平方误差目标解释数学计算；省略了库内部浮点加速及直方图累计的实现细节。

```text
基础分数 = 全部49,881个答案的平均数
本次基础分数约为0.0050019045
每一行的当前预测 = 基础分数
规则清单 = 空

最多执行180轮：
    对每一行：
        当前误差 = 答案 - 当前预测

    从100个输入列中按80%比例抽取本轮候选列。
    本轮开始时，所有行都在一个组里。
    当前末端组列表 = [全部行]

    在本轮建立if/else规则，直至不能继续或达到15个末端组：
        对每个还没达到5层深度的末端组：
            对本轮每个候选列：
                对该列由训练数据生成的有限候选分界点：
                    左组 = 此列数值 <= 分界点的行
                    右组 = 此列数值 > 分界点的行

                    如果左组或右组少于160行：
                        不允许这次分组
                    否则：
                        左误差和 = 左组的当前误差加总
                        右误差和 = 右组的当前误差加总
                        原误差和 = 左误差和 + 右误差和

                        分组改善分数 =
                            左误差和的平方 / (左组行数 + 12)
                            + 右误差和的平方 / (右组行数 + 12)
                            - 原误差和的平方 / (原组行数 + 12)

        从所有当前组的合法分法中，选择改善分数最大的分法。
        如果最大改善分数 <= 0：
            停止继续分组
        否则：
            保存“哪列 <= 哪个分界点”的判断。
            将对应原组替换成左组和右组。
            继续寻找下一次分组。

    对本轮每个最终末端组：
        完整修正 = 组内当前误差加总 / (组内行数 + 12)
        实际加入模型的修正 = 完整修正 * 0.035

    对每一行：
        找到这行在本轮进入的一个末端组。
        当前预测 += 这个末端组的实际修正

    保存本轮整套if/else和每个末端组的修正。
    下一轮重新计算“答案 - 当前预测”。

注意：一棵树分组期间，不是每经过一个if就加一次分。
一行走到一个末端组以后，这棵树只给它加一次修正。
本例实际保存180棵树；库在无法形成后续有效树时可以提前结束。
```

为什么计算组内修正：对同组各行统一加一个数c，选择使“组内所有(当前误差-c)²之和 + 12c²”最小的c。其解就是误差和/(行数+12)。先按完整修正比较分组收益，再乘0.035小步加入模型。12惩罚过大的修正；0.035控制每一轮实际修改幅度。

首轮真实数据：全部49,881行的答案平均约0.0050019045。第一条规则是046排名数<=-0.1959848478。左组14,957行，误差和-960.687507；右组34,924行，误差和+960.687507。分组改善分数约88.0729，与保存模型一致到显示精度。分界点-0.3883219957代入整批数据的改善分数约67.1701；0.0505102053约61.7758。这是对可用分界点的复算比较，不是额外保存的完整训练候选日志。

分完首条规则以后，左组的下一次分组改善分数为13.9574，右组为13.6894，所以先分左组。每增加一个分组后重新比较当前全部可分组，直到停止条件成立。

第一棵树中的一个末端组有9,945行，误差和624.677870，实际修正为0.035*624.677870/(9945+12)=0.0021958145。本组首轮预测约为0.0071977191。

第二轮重新计算每行误差。其首条规则仍选046的同一个分界，但左、右组的新误差和变为-927.290248、+927.005469，改善分数变为82.0407。其后规则用这一轮的新误差继续建立，不能把第一轮的答案差重复使用180次。

全体训练行的平方误差加总：起始4156.3276；第1轮4145.6572；第2轮4135.5447；第3轮4125.7946；第180轮3761.9716。训练误差下降不是未来收益保证。

```text
给一条新股票记录预测：
    分数 = 保存的基础分数
    对保存的每一棵树：
        只读取这条股票记录的输入数字。
        按树中if/else逐层判断，走到一个末端组。
        分数 += 这个组保存的修正值。
    输出分数。

这里不读取这只股票未来收益，也不计算它的误差。
未来答案还没有发生时，没有误差可以拿来训练。
```

范围：本次训练答案在-0.49至0.5之间，但代码没有把输出硬性裁剪到这个范围。对这份保存模型，将每棵树最小输出相加、最大输出相加，得到所有输入均满足的保守边界约[-0.597452083, 0.553511037]；各棵树极端分支未必能同时到达，因此不是说实际输出一定能到这两个端点。真实训练记录的预测范围约[-0.250344, 0.157881]。正常读取这份有限模型的预测是确定的有限加法，不是从所有实数中随机取值。

金融含义：用过去每只股票当天的信息预测它随后相对其他股票的表现，依据是历史统计关系可能部分延续的研究假设。相关性、分组公式和平方误差不能证明经济因果，也不能自动保证扣费后盈利；100、180、12、0.035均是算法设置，不是金融规律。
